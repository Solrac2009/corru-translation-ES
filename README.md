# corru-translation-ES
A repository to keep the files relating to the fan translation of the web-game corru.observer.
Un repositorio para mantener los archivos relacionados con la traducción fan del juego web corru.observer.

You can help review previous translations or translate parts of the game that have not yet been translated.
Puedes ayudarnos revisando traduciones previas o traduciendo partes del juego que no se han traducido todavía

(We pull from the russian translation and replace theirs with ours)
(Copiamos la traducción rusa y reemplazamos con lo nuestro)

Import the mod by pasting https://solrac2009.github.io/corru-translation-ES/cor-RU-main/cor-RU.js on the mod importer field
Importa el mod pegando https://solrac2009.github.io/corru-translation-ES/cor-RU-main/cor-RU.js en el campo para importar los mods
